# issues-demo

Track work the GitHub way with **Issues**.

## What this teaches
- Opening an Issue
- Using labels
- Linking commits/PRs to Issues
- Closing an Issue when the work is done

## Try it
1. Open a new Issue titled `Add a thank-you line to THANKS.md`
2. Add label `enhancement` (create it if needed)
3. Edit `THANKS.md` and commit with message: `Fixes #1` (use your issue number)
4. Watch the Issue close automatically

## Why it matters
Issues are the backlog. Closing them from commits keeps history honest.
